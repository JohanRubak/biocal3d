PASS: 10 workflow tests for preprocessing/rebuild integration, portable labeling
study creation/relocation, independent ratings and agreement analysis.
PASS: rendered desktop smoke test with real OpenGL on a virtual X display:

PASS: installer copies all referenced update files, backs up old code and leaves
existing environment, dataset and annotation sentinels unchanged.

New checks cover:
- Source bodies copied once; reuse across cache instances/app restarts.
- Source replacement invalidation and repair of a damaged local copy.
- Missing sources never silently replaced by an offline/stale cached input.
- Unwritable local cache falls back to the original source.
- Cache size eviction and exclusion of working labels, pointers and lock files.
- Logical mesh paths and annotation paths remain in the selected shared dataset.
- New shared review versions are not bypassed by local cached geometry.
- Folder walks prune annotation history before traversal; scan manifest metadata
  handles sibling review formats without per-sample JSON reads.
- Frame reuse, lazy normals, and one requested initial view render.
- Loading IO runs on a worker while Qt timers continue, progress uses real counts,
  exceptions release loading state, and the modal indicator is retired before
  an immediate next navigation key.

Validation environment: Linux Python 3.12, VTK 9.3.1, PySide6 6.8.3,
plyfile 1.1.3. Existing Windows Python 3.11 dependencies remain sufficient.
No actual O: drive, server latency or user's latest dataset was available.
No quantitative network-loading speedup is claimed. First uncached reads, shared
label saves and shared approval checks still require access to the source drive.
VTK view preparation/rendering still run on the main interface thread; IO workers
and progress feedback do not imply every operation is asynchronous.

BENCHMARK_RESULTS.json is the inherited synthetic v3.9/v3.10 IO comparison,
not an O: drive or v3.12 end-to-end loading measurement. The application writes
local loading_times.csv to aid diagnosis on the actual Windows PC.

BENCHMARK_RESULTS.json records synthetic IO measurements on 318402 triangles.
Median of three repeats in this environment:
  Label-colored PLY:     v3.9 12.075 s   v3.10 1.846 s
  Original-color PLY:    v3.9  9.895 s   v3.10 0.965 s
  Read binary PLY:       v3.9 16.100 s   v3.10 0.374 s
Timings varied with system load. These measure IO tasks, not full application
latency, and must not be extrapolated to the user's Windows PC or real scans.

Limits: the user's latest approved experimental dataset and Windows graphics
stack were not available. First-open texture/normal/locator setup is still
synchronous. Rendering remains dependent on mesh size and graphics drivers.
This update does not claim to fix the previously reported Windows/VTK shutdown
popup. No geometry simplification or changes to segmentation rules were made.
